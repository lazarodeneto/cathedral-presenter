# Visual polish prompt

```text
Review the Church Presenter app as a senior product designer and improve the interface without changing the core workflow.

Compare the implementation against these project references:
- `assets/reference/church-presenter-first-screen.png`
- `assets/reference/church-presenter-bible-library.png`
- `assets/reference/church-presenter-live-service.png`
- `assets/reference/church-presenter-workspace.png`
- `assets/reference/church-presenter-add-slide.png`
- `assets/reference/church-presenter-slide-editor.png`

Keep the three primary screens visually coherent as one product system: Home, Bible Library, and Live Service.

Preserve the three-pane operator layout. Improve hierarchy, spacing, typography, selection states, focus states, button clarity, preview framing, and presentation-mode confidence. Use a modern minimalist macOS-inspired glassmorphism style: translucent charcoal panels, subtle blur, warm ivory type, Golden Gate amber/copper highlights, restrained violet selection, fine borders, soft depth, and quiet motion.

Remove anything that looks like a generic SaaS dashboard: fake metrics, unnecessary cards, decorative badges, noisy gradients, excessive rounded containers, and placeholder copy. Make the slide canvas the visual center of gravity. Make current output, next output, message popup, blank, and Present controls unmistakable. Use glass panels only when they improve hierarchy and depth.

Check the laptop viewport, keyboard navigation, contrast, empty states, and reduced-motion behavior. Keep all visible controls functional.

Also review security communication: local versus online content, provider status, export contents, permission errors, rejected imports, and audience-output destination should be clear without exposing secrets or private data.
```
