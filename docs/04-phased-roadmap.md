# Church Presenter — Phased Roadmap

## Phase 1 — Clickable operator prototype

- Implement the Home, Bible Library, Slide Editor, and Live Service surfaces against the approved visual reference set.
- Desktop workspace shell.
- Seeded Sunday service.
- Calendar list with service search and service duplication.
- Rundown selection and reordering.
- Slide canvas with editable text.
- Bilingual scripture slide layout with primary and secondary translations.
- Local Bible and song libraries connected to the add-content flow.
- Bible library first milestone: offline search, passage preview, bundled open translations, import boundary, and bilingual slide creation.
- Editor media tools: image/video upload, URL media, QR code generation, and authorized YouTube embed/import flow.
- Current/next preview.
- Present mode, next/previous, blank, message popup.
- Local persistence.

## Phase 2 — Content libraries

- Searchable songs library.
- Bible passage picker with multiple mock translations.
- Reusable announcement and sermon slide templates.
- Import/export a service as JSON.
- Duplicate service.

## Phase 3 — Production polish

- Keyboard shortcut overlay.
- Undo/redo history.
- Slide transitions.
- Theme manager.
- Notes for operator and speaker.
- Better media handling.
- Audience and confidence monitor views.

## Phase 4 — Desktop packaging

- Tauri desktop wrapper for macOS and Windows installers.
- Fullscreen output windows on selected monitors.
- Local fonts and media permissions.
- Offline-first startup and recovery.
- Export/import and backup of local church data.
- Startup/recovery behavior.
- Auto-save and crash recovery.

## Phase 5 — Real integrations

- Licensed Bible providers.
- Song provider integrations such as JEM where permitted.
- Cloud backup and team collaboration only after the local workflow is stable.
